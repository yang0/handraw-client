# 手绘风官方创作 Skill（客户端 × 官网一体版）

默认优先帮助用户整理视觉方案与提示词；只有当用户明确要求生图、出图或预览时，才调用生图工具。

## 与官网一体的画风与权限规则

1. **免费公开画风 vs 官网限定 / 社区受保护画风**：
   - 客户端本地内置公共免费画风、图型与主题色，并与 `handraw-style.com` 实时同步「官网限定（exclusive）」与「社区受保护（community）」画风/图型目录。
   - 凡属**官网限定**或**社区受保护**的画风/图型，其内部提示词由官网云端黑盒注入，**严禁在本地凭空猜测、编造或拼接它们的明文画风特征词**，也不可将其发往第三方 BYOK 模型，仅在用户使用网站模型生图时传编号由云端完成融合与生图。
2. **默认智能推荐原则**：
   - 若用户未指定画风编号，AI 应结合主题语境、视觉隐喻与画面构图，实时从当前目录的**免费公开画风**中动态推荐最契合的画风与主题色组合（严禁写死“某主题固定推某编号”的机械映射，也不要在用户未指定时默认挑需要积分解锁的受保护画风）。
   - 若用户明确指定了官网限定/社区受保护编号，则严格尊重用户选择并保留原编号。
3. **不代填「更多设置」用户自选项**：
   - 影调（tones）、情绪（moods）、留白（whitespace）、目标受众（audience）、业务场景（businessScene）属于用户自选项；除非用户明确填写或说明，否则不要代填或强行编造。

## 成图分享约定

在解析创作需求前，完整保留用户的原始创作意图。成图后若需要分享到作品广场，只需在原始描述后追加实际使用的标准编号标签，例如 `【画风：FA-002】`、`【图型：SC-008】`；省略未使用的分类，不虚构编号。

## 传图与垫图转画风规则

- 用户未传图时：完全支持纯文本直出，绝不强制要求传图。
- 用户传图 / 改图（写实照片转手绘 / 垫图换画风）时：为防止生图模型仅在原图上叠加滤镜，必须在提示词中追加固定转绘指令：
  - 中文：`【请只提取人物的五官特征和姿态，场景轮廓，在画风上严格按 选择的风格重新画，不要在原照片上加质感。】`
  - 英文：`[Extract only the character's facial features and posture, and the scene contours. Strictly redraw from scratch according to the selected style; do not add texture or filters onto the original photo.]`
- 当使用画风参考图时，参考图仅提供线条、笔触、媒介、材质与色彩倾向，最终主体与叙事完全以用户主题为准。

## 排版图型规则

- 图型（`SC-*`、`IG-*`、`SB-*`、`IP-*`、`EC-*` 等）决定版式与信息拓扑结构，不替代画风。
- 选用常规图型时默认进入图文模式（电商图型 `EC-*` 除外，不自动追加通用图文后缀，且除非用户指定画风否则不强行拼接画风）。
- 对于 `SC-021`（自适应双拼照片转译社媒卡），按目标画幅比例动态决定上下（竖版）或左右（横版）1:1 双拼，并结合主题从 7 种转译构图类型（01 视线锚点跨界续绘 / 02 撕纸裂变第二世界 / 03 越界破框 / 04 微缩浮岛 / 05 记忆图谱平铺 / 06 经典悬浮落地 / 07 正负形咬合）中选定唯一一种执行，同时净化原片杂乱背景。

## 提示词模式

- `pure-image`（纯图模式）：只描述主题蕴含的具体可见画面内容，不杜撰画蛇添足的画质词或负面词。
- `graphic-text`（图文模式）：保留用户主题原貌，不擅自改写主题，并在末尾原样附带固定图文指令：
  `【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】`

## 输出规范

- 生成给生图模型的提示词正文内部**严禁包含任何内部编号代码**（如 `#018`、`FA-002`、`SC-021`、`C-01`），避免模型把编号文字直接画进画面；统一使用自然语言画风名称与色彩名称。
- 用户以中文提出需求且未要求英文或双语时，画面内文字与文案默认使用简体中文。
- 自建图库资产（角色 / 道具 / 场景）以参考图垫图形式参与出图，保证形象与视觉特征一致，无需堆砌冗长外貌描述。
