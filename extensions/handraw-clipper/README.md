# 手绘风灵感捕手（Chrome / Edge 扩展）

刷 X (Twitter) 或任意网页看到惊艳的图片与提示词时，一键直达本机「手绘风客户端 → 灵感库」，自动调用 AI 剥离推文废话、翻译中文并提炼可替换的「做同款」变量槽位。

## 30 秒安装与配对

1. 打开 Chrome 或 Edge，地址栏访问 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择本目录：`extensions/handraw-clipper`。
3. 打开手绘风桌面客户端，进入 **💡 灵感库 → 🧩 Chrome 灵感捕手**（或 **设置 → 通用偏好**），复制 **本地桥接地址** 与 **配对 Token**，粘贴到扩展弹窗并点击 **测试并保存连接**。

## 日常使用方式

- **X (Twitter) 专属捕手**：每条带图或文字推文的操作栏会自动出现 `📌 收进手绘风` 按钮，点击即可把高清原图（`name=large`）与完整推文直传灵感库。
- **全网任意页面**：在任意图片或选中文字上右键 → **收进手绘风灵感库**，或点击扩展图标里的 **📌 采集当前页**。
- **离线云端暂存（可选）**：如果在弹窗中填写了手绘风官网令牌，即使本机桌面客户端没开，灵感也会先安全存进官网暂存箱，下次打开客户端自动同步下来。
