## 1. 产品定位

手绘风生图工作台是 Windows 和 macOS 桌面客户端。它把 Skill 的本地资源库和网站的账号、计费、社区连起来。

**一句话：370 种手绘画风装在桌面上，挑风格像翻画册，出图像按快门，作品留在自己电脑里。**

### 和竞品的区别

| | Midjourney / Krea 等 | 网站创作台 | Skill | **桌面工作台** |
| --- | --- | --- | --- | --- |
| 风格从哪来 | 风格代码、训练模型 | 网站资源库 | 本地资源库 | 本地资源库 + 网站资源 + 自建 |
| 选风格时能否预览 | 需要先生成 | 示例图 | 画廊网页 | 示例图即时预览、并排对比 |
| 图片存在哪 | 云端 | 云端，生成即公开 | 本地 | 本地，主动发布才公开 |
| 模型 | 平台模型 | 网站模型 | 自己的接口 | 网站模型或自己的接口，每次可选 |
| 离线 | 不能 | 不能 | 能 | 浏览、整理、用自己接口生成都能 |

### 目标用户

1. **内容创作者**：公众号、小红书、知识博主。需要封面、配图、多图卡片，要求一组图风格一致。
2. **插画爱好者**：喜欢收集和试验风格，想建立自己的画风。
3. **有自己接口的进阶用户**：使用自己的密钥，同时使用网站的风格库。

### 设计原则

1. **先看到，再花钱**：选择风格、组合参数时用本地示例图预览，确认后才调用付费模型。
2. **本地优先**：启动快、离线可用；网络只用于账号、计费、同步和社区。
3. **一组图要一致**：系列图、文章配图默认锁定同一套「配方」。
4. **快**：命令面板、全局快捷键、拖拽，常用操作不超过两步。
5. **费用透明**：每次生成前显示花费；不弹多余确认，用户设置的上限以内直接执行。

## 2. 招牌体验

这六个体验决定产品的特点，优先保证它们做好。

### 2.1 风格画册（Style Atlas）

把资源库做成可以翻的画册，而不是一个下拉列表。

- **画册视图**：全屏瀑布流展示画风示例图，按流派分组（FA 国际社论幽默、水墨、日系等），左侧流派目录可快速跳转。悬停卡片显示编号、名称、特征摘要，以及快捷操作：「用于创作」「加入对比」「收藏」「找相似」。
- **找相似**：按画风特征文字和标签计算相似度，显示最接近的 12 个画风。
- **对比台**：最多选 4 个画风并排，显示示例图和特征说明；把同一个主题套到这几个画风上，一键各生成一张进行真实对比（显示总价）。
- **以图找风格**：把任意图片拖进画册，用视觉模型（网站提供，费用由网站承担）描述它的视觉语言，然后在 370 个画风中找出最接近的 5 个，并给出「据此新建我的画风」入口。
- **画风骰子**：随机抽取画风 × 图型 × 主题色组合，适合找灵感；可锁定其中一项再抽。

### 2.2 配方（Recipe）

一套可复用的视觉设定，是所有创作入口的共同单位。

- 配方 = 画风（可两种融合）+ 图型 + 主题色 + 影调 + 比例 + 情绪 + 留白档位 + 参考图 + 补充说明。
- 任何时候可以「存为配方」，命名，如「我的公众号封面」。
- 配方卡片显示组合缩略图（画风示例图 + 色板 + 图型示意）。
- 系列图、文章配图、画布节点都引用配方，修改配方后可以选择重新生成受影响的图。
- 配方可以导出为文件或分享到网站（网站已有 `/api/studio/recipes`），别人导入后直接使用。
- 首页默认提供十几个官方配方：公众号封面 2.35:1、小红书 3:4 多图、知识卡片、漫画四格、海报等。

### 2.3 快门（Quick Shot）

随时随地出一张图。

- 全局快捷键（默认 `Alt+Space` / `⌥Space`）在任何应用上方唤起一条悬浮输入框。
- 输入主题，`Tab` 切换配方（默认上次使用的），回车生成。生成中显示进度，完成后显示缩略图。
- 结果自动存入本地作品库，同时可以：复制到剪贴板（直接粘贴到公众号编辑器、微信、Figma）、拖出为文件、按 `Enter` 打开到主窗口继续编辑。
- 支持选中文字后唤起：把选中的文字作为主题。

### 2.4 批注改图

借鉴 Lovart 的方式改图。

- 在作品上任意位置点击，添加批注，例如「这里加一只猫」「背景换成夜晚」。也可以框选区域。
- 可以连续加多条批注，点「全部执行」后一次生成新版本。
- 有局部重绘能力的模型使用蒙版；不支持时把批注合成到提示词，用整图编辑。界面会说明使用了哪种方式。
- 每次修改生成新版本，原图保留。版本以时间线显示，可以回到任意版本继续改。

### 2.5 文章到图文

把一篇文章变成一套配图。

1. 粘贴正文、导入 Markdown / DOCX，或粘贴公众号文章链接。
2. 选择配方（或让系统根据文章推荐 3 个配方，每个显示示例效果）。
3. 自动规划封面和正文配图位：每个配图位显示在正文旁边，有主题描述，可以修改、删除、新增、拖动位置。
4. 先生成封面作为样片，确认风格后批量生成其余配图。
5. 导出：带图 Markdown、公众号可粘贴的 HTML、图片 ZIP；一键复制到公众号编辑器。

### 2.6 画布

无限画布，用来做大量组合和流程。

- **自由画布**：作品、参考图、便签可以随意摆放，按 Frame 分组。适合做情绪板和多方案对比。
- **节点模式**：主题节点、配方节点、画风/图型/颜色节点、参考图节点、生成节点、批注改图节点、导出节点，连线后执行。例如「3 个主题 × 2 个画风 = 6 张」。
- 执行前显示将生成多少张、总费用；超过设置上限时要求确认。
- **工作流模板**：小红书 6 图、IP 角色三视图、漫画四格、商品主图等，打开即用；用户的工作流可以保存成模板。
- **助手搭建**：输入「帮我做一套 6 张的小红书咖啡店探店图」，助手生成节点和连线，用户确认后执行。

## 3. 功能需求

编号 F1–F12 对应原始需求 1–12，F13 起为新增。

### F1 登录网站账号

- 使用网站设备码授权（`POST /api/auth/device` → 浏览器批准 → `POST /api/auth/device/token`），得到 `hwt_` 令牌。客户端不收集网站密码。
- 流程：点「登录」→ 打开系统浏览器授权页并在客户端显示验证码 → 用户在网页批准 → 客户端显示头像和用户名。
- 也支持 `handraw://` 协议回跳：网页批准后自动唤回客户端，不需要等待轮询。
- 令牌保存在系统凭据库（Windows 凭据管理器 / macOS 钥匙串），不写明文文件。
- 退出登录时删除本机令牌，并请求网站撤销该设备令牌。
- 令牌失效时提示重新登录，本地创作不中断。
- 如果 Skill 已登录（`~/.handraw-style/cloud_auth.json` 有有效令牌），提示是否使用同一账号。

### F2 浏览资源列表

| 列表 | 数据来源 | 当前数量 |
| --- | --- | --- |
| 画风 | `references/styles.json` + `images/individual/` | 370 |
| 图型 | `references/layouts.json` + `images/layouts/` | 170 |
| 主题色 | `references/colors.json` + `images/colors/` | 约 40 |
| 影调 | `references/tones.json` + `images/tones/` | 16 |
| 角色 / 道具 / 场景 | 资源包 + 个人图库 | 随用户 |
| 配方 | 官方配方 + 我的配方 + 网站配方 | 随用户 |
| 我的资源 | 本地自建 + 网站已解锁资源 | 随用户 |

- 画风使用「风格画册」视图（2.1），其他列表使用网格视图，可切换。
- 通用功能：编号搜索（`FA-013`、`IG-038`）、名称/作者/关键词搜索、分类筛选、收藏、最近使用。
- 详情页：大图、编号、中英文特征、作者与授权、示例图、「用于创作」「加入配方」「找相似」。
- 来源标签：官方 / 社区已解锁 / 我的。

### F3 创作：单图、系列图、文章配图、画布

四个独立入口，共用配方、生成执行和本地保存，各自表单状态互不影响（与网站 `docs/studio-model.md` 一致）。

**单图工作区**布局：

```
┌───────────┬──────────────────────────────┬──────────┐
│ 配方面板   │          结果区               │ 历史条    │
│ 画风 ▣▣    │  ┌────────┐ ┌────────┐        │ ▢        │
│ 图型 ▣     │  │ 预览   │ │ 生成结果│        │ ▢        │
│ 主题色 ●●● │  └────────┘ └────────┘        │ ▢        │
│ 影调 ▣     │                               │          │
│ 比例 情绪   │                               │          │
├───────────┴──────────────────────────────┴──────────┤
│ 主题输入……                      模型 ▾  ¥0.30  [生成]  │
└─────────────────────────────────────────────────────┘
```

- 底部输入栏：主题、模型选择、价格、生成按钮。`Ctrl/⌘+Enter` 生成。
- 「预览」位置在生成前显示示例图合成的效果示意（画风示例图 + 图型示意 + 色板），零费用。
- 提示词面板可展开，显示最终中英文提示词，可复制，可手动修改（修改后标记为「自定义」）。
- 「扩写」按钮：把简短主题扩写成更完整的画面描述（使用文字模型，可撤销）。
- 一次可生成 1–4 张变体。
- 图生图、改图、批注改图（2.4）、扩图、放大。

**系列图**：一个配方 + 多个主题（逐行输入、从表格粘贴、或让助手根据一个话题拆成 N 个主题）。可以逐张换图型。网站模型每批最多 5 张、串行执行；失败的单张可重试。支持导入 CSV 批量生成（参考 Ideogram）。

**文章配图**：见 2.5。规划使用网站免费规划接口 `/api/studio/article-plan`，或用户自己的文字模型。

**画布**：见 2.6。

### F4 生成结果默认保存在本地，可选发布

- 每次生成保存到 `<作品目录>/<日期>/<runId>/`：原图、缩略图、`run.json`（原始创作指令、配方、资源编号、模型、耗时、费用、版本关系）。
- 「本地作品」页面：时间线和网格视图；按配方、画风、模型、是否发布筛选；全文搜索主题；星标；在文件夹中显示；删除进回收站。
- 「发布到网站」：选择一次任务中的若干图片，填写标题和说明，预览公开内容（图片 + 原始创作指令 + 关联画风/图型）后确认。
  - 一次任务发布为一件多图作品（与网站 V3 一致），返回作品链接。
  - 用 `runId` 作为幂等键，重复点击不重复发布；已发布作品显示「已发布 · 查看」以及点赞、评论数。
- 用网站模型生成时，结果同样只存本地、不自动公开。这需要网站改动 W2。

### F5 自定义画风和图型

- **从参考图新建画风**（参考 Recraft）：拖入 1–5 张参考图，可调每张权重 → 视觉模型（网站提供，费用由网站承担）提取视觉语言 → 生成中英文特征草稿 → 用户编辑确认 → 用同一主题试生成 2 张验证 → 保存。
- 特征只允许描述视觉语言（媒介、线条、材质、色彩、光影、构图），不写参考图中的人物、服装、物品和场景。提取时自动检查，并在编辑页标出违规词。
- 也可以手动填写特征，或从现有画风「另存为我的画风」再修改。
- **新建图型**：名称、布局约束说明、示意图（可上传或手绘草图）。
- 自建资源使用本地编号（`MY-S-001`、`MY-L-001`），不与官方编号冲突，创作时和官方资源一样可选。
- **登录后默认同步到网站个人资源**（`PUT /api/v1/me/resources/{id}`，`visibility=private`）。设置中可以关闭。
  - 同步不等于公开，公开需要在网站上操作。
  - 带 `baseRevision` 检测冲突，冲突时并排显示本地版和网站版，由用户选择。
  - 新设备登录后自动拉取个人资源和已解锁的社区资源。
- 数据格式与 Skill 个人库一致（`skill-addon/scripts/personal_library.py`），Skill 和客户端可以读同一份个人库。

### F6 资源图片从本地加载

- 安装包内置资源包：资源定义 JSON 和 WebP 缩略图、示例图（当前约 60 MB）。
- 所有列表和创作页的资源图片读本地文件。缩略图首次加载后建索引，画册滚动保持流畅（目标 60 fps，370 张卡片首屏 < 300 ms）。
- 网站社区资源和已解锁资源首次使用时下载到本地缓存，之后读本地。
- 资源包随 F7 增量更新。

### F7 版本检查和增量更新

- 检查时机：每次启动、此后每 6 小时；设置页可以手动检查。
- 版本信息来自 GitHub Releases（程序 `latest.yml`、资源包 `manifest.json`）；GitHub 不可达时依次回退到 Gitee 镜像和网站静态地址。
- 有新版本时顶栏显示「有更新」，点击显示版本号和更新说明，按钮「立即更新」。
- 两类更新分开：
  1. **程序更新**：下载新版本程序（约 25–30 MB），校验 SHA-256 和 ed25519 签名后替换，提示「重启以完成更新」，也可以选择下次启动时更新（见 5.1.2）。
  2. **资源包更新**：对比 `manifest.json` 中每个文件的 SHA-256，只下载新增和变化的文件，校验后替换，不需要重启。新上架的画风在画册中显示「新」标记。
- 下载或校验失败时保留旧版本。用户自建资源、配方和本地作品不受更新影响。

### F8 网站收藏和生图历史

- 「我的收藏」：作品、画风、图型、配方，数据来自 `GET /api/v1/me/collection-items`。点击在浏览器打开网站页面；画风/图型/配方已解锁时可以「用于创作」。
- 「网站生图历史」：数据来自 `GET /api/v1/me/generations` 或 `/api/studio/history`，显示缩略图、时间、模型。点击打开网站页面，也可以「下载到本地作品」。
- 未登录时显示登录引导。

### F9 首页发现

- 首页混排公开作品、画风、图型和独立论坛帖子，最多 50 张。各类型优先显示新发布内容；没有发布时间的官方资源沿用目录顺序。
- 缩略图按需下载并缓存到磁盘。发现列表短期缓存，网站暂不可用时仍可显示上次成功加载的列表和已缓存的缩略图。
- 点击卡片打开网站详情，「浏览全部」打开网站首页；不设独立社区页。

### F10 自定义生图接口

- 设置 →「我的接口」：可添加多个接口，填写名称、类型、Base URL、API Key。第一版支持 OpenAI 兼容接口（`/images/generations`、`/images/edits`），接口结构预留 Gemini 等其他类型。
- 「获取模型」：调用 `GET {base}/models`，列出模型，用户勾选图片模型、修改显示名称，并可填写单价用于本地统计。
- 「测试」：发送最小请求，显示真实错误信息（鉴权失败、模型不存在、超时等）。
- 每个模型可设置支持的尺寸、比例、是否支持参考图和局部重绘；不确定时保持默认，生成失败后提示调整。
- 密钥保存在系统凭据库，不同步到网站，不写入日志和作品记录。
- 文字模型接口单独配置，用于扩写、文章规划、特征提取、以图找风格。

### F11 默认使用网站模型（扣费）

- 模型选择器分两组：「网站模型」和「我的接口」。默认选网站推荐模型。
- 网站模型列表来自 `GET /api/economy/public-models`，显示名称、分辨率、单价、是否可用免费额度。
- 生成前调用 `POST /api/studio/quote` 报价，底部输入栏显示「免费额度 1 张」或「¥0.30」。
- **单次费用上限**（默认 ¥2，可设置）：报价在上限内直接生成，超过时弹出确认。不再对每次生成都弹确认。
- 执行、扣费、失败退还由网站完成；客户端取回图片存本地。
- 未登录时提示登录；余额不足时提示充值，按钮打开网站钱包页。
- 使用「我的接口」时不扣网站费用。

### F12 余额与免费额度同步

- 顶栏显示人民币余额和免费额度（如「¥12.30 · 1K 剩 8 张」），点击展开明细，有「充值」按钮打开网站钱包页。
- 数据来自 `GET /api/economy`，在启动、登录、每次网站模型生成结束、窗口重新获得焦点时刷新。
- 余额只用于显示，不作为客户端计费依据。

### F13 命令面板

- `Ctrl/⌘+K` 打开，可以：搜索画风/图型/配方/作品、切换页面、执行操作（「新建系列图」「检查更新」「复制最后一张图」）。
- 输入 `FA-013` 直接打开该画风；输入 `/封面 春天的咖啡馆` 用「公众号封面」配方生成。

### F14 本地任务队列

- 所有生成任务进入队列，顶栏显示进行中数量，可展开查看。
- 关闭窗口时若有任务在执行，提示是否最小化到托盘继续。完成后系统通知。
- 网站模型任务在客户端重启后按任务 ID 继续查询结果，不重复扣费。

### F15 导出与分享

- 一组图导出 ZIP；文章导出带图 Markdown / 公众号 HTML。
- 「小红书格式」：按 3:4 导出并按顺序命名。

## 5. 技术方案

### 5.1 架构：参照 Magpie

已确认参照 [Magpie](https://github.com/yetone/magpie) 的做法。Magpie 是一个 Go 单文件程序，macOS 安装包约 40 MB，Windows 约 90 MB（含大量网关组件），带托盘、主窗口、插件和签名校验的自更新。本产品采用同样的结构：

```
handraw.exe / 手绘风.app（一个 Go 程序）
├─ 原生壳：Wails v3 —— 托盘、主窗口、快门悬浮窗、全局快捷键、handraw:// 协议、单实例、开机启动
├─ 本地服务：Go HTTP（只监听 127.0.0.1）—— JSON API、资源文件、生图请求、任务队列、同步、更新
├─ 界面：内嵌的 Web 页面（系统 WebView：Windows WebView2、macOS WKWebView），不带浏览器内核
├─ 存储：SQLite（modernc.org/sqlite，纯 Go，免 CGO）+ 本地文件
└─ 插件运行时：内置插件（Go 包）+ 社区插件（Web 页面插件，沙箱 iframe）
```

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 原生壳 | Wails v3（Magpie 同款） | 用系统 WebView，不打包 Chromium，体积小；托盘、多窗口、快捷键、剪贴板、通知都有 |
| 后端 | Go | 一个可执行文件，跨平台编译；并发生图、文件处理、更新校验简单 |
| 前端 | 原生 JS + 少量库，不使用重型构建（Magpie 同样无打包器）；画布部分可引入独立的小型库 | 体积小、启动快；页面也能用 `handraw web` 在浏览器中打开调试 |
| 存储 | SQLite（作品索引、FTS5 全文搜索、同步状态、任务队列）+ 文件 | |
| 凭据 | Windows 凭据管理器 / macOS 钥匙串 | 网站令牌、接口密钥 |
| 体积目标 | 程序 macOS ≈ 25 MB、Windows ≈ 30 MB；资源包另计约 60 MB | |

备注：Windows 10 旧版本可能未预装 WebView2，安装器检测到缺失时自动安装 WebView2 运行时（Win11 已内置）。

### 5.1.1 插件机制

参照 Magpie 的插件运行时（`docs/subsystems/plugin-runtime.md`），分两层：

**内置插件**（Go 包，随程序发布，用户可开关）
- 每个插件声明清单：`id`、兼容的宿主 API 版本（如 `^1`）、依赖的服务、提供的服务、设置项（自动生成设置表单）、前端文件。
- 宿主按依赖顺序启用；某个插件启动失败只影响它自己。关闭时撤销它注册的一切。
- 正在使用中的插件（例如已有画布工程）不能关闭，以免数据无处查看。
- 第一批拆成内置插件的功能：画布、文章到图文、批注改图。首页发现是核心入口，不依赖插件。

**社区插件**（npm 包或 GitHub 仓库，标签 `handraw-plugin`）
- **页面插件**：在侧栏增加一个页面，运行在沙箱 iframe 中（`sandbox allow-scripts`，禁止直接联网和访问本地 API），通过 `postMessage` 与宿主通信。
- **面板插件**：嵌入到已有页面的指定位置，如作品详情侧栏、创作页底部。
- **菜单动作**：在作品、画风卡片的右键菜单中增加项，点击后打开插件页面并传入所选对象。
- **生图接口插件**：接入新的生图服务（如即梦、Gemini、本地 ComfyUI），向宿主注册一个模型提供方。
- **导出插件**：如「发布到小红书草稿」「导出到 Obsidian」。
- 插件只能读写它声明的权限（如 `works:read`、`recipes:read`、`image:save`），安装时显示给用户。宿主对插件的每个请求重新检查权限，插件拿不到网站令牌和接口密钥。
- 插件市场：客户端「插件」页列出官方推荐和带标签的 GitHub 仓库，一键安装、更新、停用。

### 5.1.2 自动更新

参照 Magpie 的更新方式，不依赖 Apple/Windows 代码签名：

- 每次启动和每 6 小时读取 GitHub Releases 最新版本（GitHub 不可达时回退到 Gitee 镜像、网站静态地址）。
- 每个版本发布 `SHA256SUMS` 和 `SHA256SUMS.sig`。签名用项目自己的 ed25519 私钥（存在 GitHub Actions 密钥中），公钥内置在程序里。签名内容为 `handraw release <版本号>` + `SHA256SUMS`，所以一个签名只对一个版本有效，防止降级攻击。
- 客户端下载新版本 → 校验 SHA-256 和签名 → 替换程序文件 → 提示「重启以完成更新」。校验失败则丢弃，保留旧版本。
- **程序更新**：Go 程序约 25–30 MB，按整个文件下载（不做二进制差分，体积已经可接受）；为后续保留差分包扩展点。
- **资源包更新**：增量下载，按 `manifest.json` 中每个文件的 SHA-256 对比，只下载变化的文件；`manifest.json` 本身也纳入签名。
- 用户自建资源、配方、作品不受更新影响。

### 5.1.3 没有 Apple 开发者账号的影响

- macOS 版本不做公证。首次打开时系统会拦截，需要用户在「系统设置 → 隐私与安全性」点「仍要打开」，或右键 →「打开」。下载页和安装包内附图文说明。
- 由于自更新是程序自己下载和替换文件，不经过 Apple 机制，**自动更新不受影响**。下载时去除 quarantine 属性，更新后不再弹出拦截。
- Windows 版本同样暂不做代码签名，SmartScreen 首次可能提示「未知发布者」，用户点「更多信息 → 仍要运行」。以后可以购买代码签名证书解决。
- 以后有了开发者账号，只需在 CI 中加入签名和公证步骤，架构不变。

### 5.2 提示词组装

提示词规则以 Skill 为准，不在客户端另写一份：

- 把 Skill 组装逻辑（`prompt_style.py`、`resolve_reference.py`，以及网站 `skill_prompt.py` 用到的规则）中能数据化的部分（模板、比例、情绪、影调、模型能力）抽成 JSON，放进资源包。
- 客户端用 Go 实现组装器，读取这些 JSON。Skill 仓库维护一批「输入 → 期望提示词」的标准用例，Skill、网站、客户端三方都跑同一批用例，保证输出一致。
- 规则更新随资源包增量下发，不需要更新程序。
- 不在客户端内置 Python。
- 使用网站模型时，以网站服务端解析结果为准。

### 5.3 本地数据目录

```
<用户数据目录>/handraw-client/
  resources/            资源包（可增量更新）
    manifest.json
    references/*.json
    images/...
  library/              个人画风、图型、图库（与 Skill 个人库格式一致）
  recipes/              我的配方
  cache/remote/         网站资源缓存
  works/<date>/<runId>/ 本地作品（目录可在设置中更改）
  canvases/             画布工程
  db.sqlite             索引、同步状态、任务队列
  logs/                 不含密钥
```

Windows：`%APPDATA%\handraw-client`；macOS：`~/Library/Application Support/handraw-client`。

### 5.4 发布与更新

- 仓库：公开仓库 https://github.com/yang0/handraw-client 。
- GitHub Actions 在 Windows（x64、arm64）和 macOS（arm64、amd64）上构建，产出 `handraw-windows-amd64.exe`、`handraw-darwin-arm64.dmg` 等，连同 `SHA256SUMS`、`SHA256SUMS.sig` 发布到 Releases，并同步到 Gitee 镜像。
- 资源包：由 handraw-style 仓库生成 `manifest.json`（路径、大小、SHA-256、资源版本），版本号与程序独立，同样签名。

### 5.5 开发流程

- 每个新功能或缺陷先在 handraw-client 仓库创建 GitHub Issue：说明需求、预期行为、验收标准；然后开发。
- 提交信息引用 Issue 编号；完成后在 Issue 中记录提交、实际运行的测试，以及未完成的手动验证。
- 只有实际验证过界面和交互后才关闭 Issue，不能只凭代码提交就关闭。
- 涉及网站或 Skill 的改动，在对应仓库另建 Issue 并互相链接。

## 8. 验收标准

- **离线**：断网能打开，浏览全部官方资源，用「我的接口」生成单图并保存到本地。
- **性能**：冷启动到首页可操作 < 3 秒；画册 370 张卡片首屏 < 300 ms，滚动无明显掉帧。
- **快门**：在其他应用中按快捷键到出现输入框 < 200 ms；生成后能直接粘贴到微信公众号编辑器。
- **登录**：新电脑从点击登录到显示用户名不超过 1 分钟；令牌不出现在任何明文文件或日志中。
- **网站模型**：报价与网站创作台一致；生成后余额/额度立即刷新；失败任务费用退还；图片不出现在网站作品广场；客户端中途重启后任务结果能取回且不重复扣费。
- **发布**：返回的作品链接能在网站打开，包含所选图片、原始指令和画风/图型关联；重复点击不重复创建。
- **自定义资源**：A 电脑新建画风，B 电脑登录后能看到并使用；网站上该画风为私有；提取的特征不包含参考图中的具体人物和物品。
- **文章**：一篇 3000 字文章从导入到生成完一套配图（封面 + 5 张）不超过 10 分钟，风格一致。
- **更新**：资源包只改 1 张图时只下载 1 个文件；被篡改的安装包或签名不匹配时拒绝更新；更新中断后仍能正常启动。
- **体积**：macOS 程序安装包 ≤ 30 MB，Windows ≤ 35 MB（不含资源包）。
- **平台**：Windows 10/11（x64、arm64）、macOS 13+（Apple Silicon 与 Intel）可安装、启动、更新；未签名情况下按说明能打开。
